# 📚 Library Management System

## Overview
A console-based Library Management System built using Java, JDBC, and MySQL.

## Features

- Add Book
- Update Book
- Delete Book
- Search Book
- Register Member
- Issue Book
- Return Book
- Fine Calculation

## Tech Stack

- Java
- JDBC
- MySQL

## Database

- Books
- Members
- Transactions

## Future Improvements

- GUI
- Spring Boot
- Login Authentication
